**Title:** Airline Booking A/B Test & Conversion Funnel

**Tags:** Experimentation · Statistical Analysis · Power BI · Python

**Short description:** Analyzed a simulated flight search redesign using session level booking data. Built an interactive funnel dashboard, compared conversion across experiment groups, and used a proportion test to evaluate whether the observed lift supported a rollout decision.

**Result line:** Treatment conversion was 8.73% versus 8.23% for control, but the difference was not statistically conclusive (p = 0.172).

**Disclosure:** Simulated airline case study; not a JetBlue experiment or customer dataset.
