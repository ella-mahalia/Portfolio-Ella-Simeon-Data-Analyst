# Airline Analytics: From Booking to Capacity

**One portfolio entry, two distinct analytical questions.** Open `index.html` for the combined presentation and switch between its two interactive dashboards.

1. **Booking experiment:** a simulated flight-search A/B test with a conversion funnel and a two-proportion statistical comparison. This is a hypothetical experiment, not JetBlue customer data or a real test outcome.
2. **Route forecast:** public BTS T-100 airline traffic, six JetBlue-operated nonstop routes, a 2025 holdout backtest, May–August 2026 passenger forecasts, and illustrative seat scenarios. This is independent analysis, not a JetBlue business recommendation.

The work connects product conversion with downstream traffic planning while keeping the data sources, assumptions, and findings separate. Read each subfolder's README for methodology and Power BI instructions. The combined landing page uses relative links and works offline when the folder structure is preserved.
