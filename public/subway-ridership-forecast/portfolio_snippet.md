# Portfolio copy

**Subway Ridership Forecast & Station Trends**

Built an interactive dashboard from public MTA hourly station ridership, comparing five high-volume station complexes by day and hour. Tested one-week-ahead seasonal forecasts on a held-out week, disclosed station-level errors against a prior-week baseline, and published a reproducible Python pipeline with an independently shareable dashboard.

**Tags:** Public MTA Data · Python · Time Series · Data Visualization

**Disclosure:** Public data analysis and independent portfolio project; not an official MTA forecast. Measures estimated paid station entrances, not passenger load or available capacity.
